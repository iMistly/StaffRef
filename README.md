# Staff Reference
A functional web application to find the similarities between two anime.

I am restricting myself to ordinary HTML, JS, and CSS; no external libraries or frameworks. I will also try to limit the use of AI since I believe that it will just write the whole project with little intervention and that's lame.

Anilist's GraphQL API is cool since it's free, but it's also very limited in the amount of requests you can make as an unauthenticated user.
